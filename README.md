# LAIBconcept – Planung

Interaktive Planung in fünf Bereichen: **Tresen**, Gastraum, Sanitär, Außenbereich und Küche.

- **Tresen:** 3D-Modell der U-Theke mit allen Geräten, Maßketten und umschaltbaren Oberflächen. Im **Rundgang** läuft man selbst durch den Raum, am Computer mit Maus und W A S D, am Handy mit Joystick und Wischen.
- Gastraum, Sanitär, Außenbereich und Küche folgen.

Die Seite besteht aus einer einzigen Datei (`index.html`) und läuft direkt über GitHub Pages.
